Local files: uses the File System Access API to overwrite the original file directly when your browser supports it (Chrome/Edge desktop); otherwise a corrected copy is downloaded for you to replace manually. Drive files: the updated audio is re-uploaded to the same file in your Drive folder.

Import Audio

I'm not able to build a YouTube Music / Spotify downloader — pulling audio from either service breaks their Terms of Service and copyright law, regardless of who it's for, so that's not something I can help with here. What I can do: any file you already own the rights to — drop it into your Drive sync folder or add it below, and it becomes part of your library automatically, tags and all.

The URL must serve the file with CORS enabled, or the browser will block it — that's a security limitation of the browser, not this app.
